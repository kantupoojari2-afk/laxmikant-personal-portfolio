# Laxmikant Poojari – Personal Portfolio

A responsive, dark-themed personal portfolio website built with **HTML, CSS and vanilla JavaScript** (no frameworks).

## Features
- Home, About, Skills, Projects and Contact sections
- Responsive navigation with mobile menu
- Smooth scrolling, scroll animations and hover effects
- Dark theme with gradient styling
- Footer year updates automatically

## Project structure
```
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally
Open `index.html` in any modern browser. No build step is needed.

## Customise
- **Project status:** change the `In Progress` / `Planned` labels in `index.html` as your work moves forward.
- **Project links:** once a project has its own GitHub repository, add a link inside its card.
- **Colours:** edit the CSS variables at the top of `style.css`.

## Upload to GitHub
1. Sign in at [github.com](https://github.com) and click **New repository**.
2. Name it, e.g. `portfolio` (or `kantupoojari2-afk.github.io` for a main user site). Set it to **Public**, then click **Create repository**.
3. Upload your files, using either option:
   - **Browser:** click **uploading an existing file**, drag in the four files, then click **Commit changes**.
   - **Git (terminal), inside your project folder:**
     ```bash
     git init
     git add .
     git commit -m "Add portfolio website"
     git branch -M main
     git remote add origin https://github.com/kantupoojari2-afk/portfolio.git
     git push -u origin main
     ```

## Publish with GitHub Pages
1. Open your repository and go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**, then click **Save**.
4. Wait 1–2 minutes. Your site will be live at:
   - `https://kantupoojari2-afk.github.io/portfolio/` (repo named `portfolio`)
   - `https://kantupoojari2-afk.github.io/` (repo named `kantupoojari2-afk.github.io`)
